# 第 1 步：检查环境

**谁做**：AI 跑命令；装软件前先问用户。

1. 在框架文件夹里运行 `python qa.py doctor`（Windows 不认 `python` 就用 `py`，macOS / Linux 可能是 `python3`）
2. 按结果处理：
   - 缺依赖包：问用户“要装 pytest、httpx、fastapi、uvicorn、anthropic 这几个 Python 包吗？”，同意后运行 `python qa.py setup`
   - 没有 git：请用户到 https://git-scm.com 下载安装，装完重开终端
   - 没有 Python 或版本低于 3.10：请用户到 https://www.python.org 下载安装，安装时勾选“Add python.exe to PATH”
   - Windows 建议运行 `setx PYTHONUTF8 1`，重开终端后中文不容易乱码
3. 可选：`python qa.py selftest`，在临时文件夹里把整条流程走一遍（用假模型，不花钱，约 1 分钟），确认框架本身没问题

**做完的标准**：`doctor` 结论是“可以用了”。
