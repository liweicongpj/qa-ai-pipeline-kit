# 第 7 步：AI 写接口用例并跑通一次

**谁做**：AI 写，用户审清单和断言。

1. 出清单：`{{qa}} prompt tests-plan [R001]`，照做。AI 会：
   - 按接口文档和风险清单列用例（正常、重放、并发、回包丢失、越权、边界、跨天……）
   - 对耦合关系表里被多个模块同时改的数值，列因素和取值，用 `{{qa}} combos autotest/组合因素.md` 生成两两组合
   - 列出不变量（金额不为负、资产守恒、次数不超上限……）
2. 停下来请用户审 autotest/用例清单.md
3. 写代码：`{{qa}} prompt tests-write`，照做。用例在 autotest/tests/，不变量在 autotest/invariants.py（每个用例结束后自动检查）
4. 跑：`{{qa}} autotest run`（服务没在跑、又配了启动命令时加 `--start`）
5. 有失败就归因：`{{qa}} prompt triage`（或 `{{qa}} gen triage --model haiku`），用户确认后真缺陷用 `{{qa}} defect new` 登记

**做完的标准**：有用例并且跑过一次。到这里上手就完成了，之后看 [日常用法](../日常.md)。
